# POS

Repositório com os trabalhos da pós-graduação, organizados por disciplina.

## Exercícios de JavaScript (capítulos 1 a 4)

Os exercícios de JavaScript dos capítulos 1 a 4 não ficam mais em pastas separadas: foram aplicados diretamente na interface web do projeto, em [`pos-projeto-final/frontend/`](pos-projeto-final/frontend), que consome a API Flask para gerenciar o recurso **Corridas**. O mapeamento de cada capítulo para o código está em [Onde cada capítulo foi aplicado](pos-projeto-final/README.md#onde-cada-capítulo-foi-aplicado).

## Projeto final — Programação Orientada a Serviços

- [`pos-projeto-final/`](pos-projeto-final) — Atividade 1 (Análise, Modelagem, Prototipação e Primeira Implementação) do estudo de caso **Controle de Checkpoints em Corridas de Trekking**: documentação (requisitos, casos de uso, DER, protótipo) em `docs/relatorio.pdf`, a primeira versão da API em Flask + SQLite e uma interface web (HTML, CSS e JavaScript em módulos) para o recurso Corridas, servida pelo próprio Flask (detalhes no README da pasta).
